Fields

Empty

An empty box with Min = Vector3.PositiveInfinity and Max = Vector3.NegativeInfinity. This box can be used with Extend(Vector3) to create a bounding box without a special case for the first point.

Declaration
public static readonly Box3 Empty
Field Value
Type Description
Box3
Examples

For example:

Vector3[] points = GetPoints();
Box3 aabb = Box3.Empty;
for (int i = 0; i < points.Length; i++)
{
    aabb.Extend(points[i]):
}

Will calculate the bounding box of all the points in the array without needing a special case for the first point.

Max

The maximum boundary of the box. This field is not guaranteed to be greater than Max.

Declaration
public Vector3 Max
Field Value
Type Description
Vector3
Remarks

A box with a minimum point greater than the maximum is not considered valid except for a single configuration where Min = Vector3.PositiveInfinity and Max = Vector3.NegativeInfinity as is the case with Empty.
